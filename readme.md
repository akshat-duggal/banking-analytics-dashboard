# 🏦 Banking Analytics & Prediction Dashboard

## 🌟 Project Overview

Interactive machine learning dashboard analyzing 16.5 years of banking transaction data from 317 Indian banks (2008-2024).

### Key Features
- 📊 **17 ML Models** (Classification, Regression, Clustering, Deep Learning)
- 🎯 **97.11% R² Accuracy** in transaction prediction
- 🌍 **Economic Impact Analysis** with 5 major events
- 🎨 **Bank Segmentation** into 4 distinct clusters
- 💡 **Actionable Insights** for banks, regulators, and investors

### Technologies Used
- Python 3.8+
- Streamlit
- Plotly
- Scikit-learn
- Pandas & NumPy

### Local Setup
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/banking-analytics-dashboard.git
cd banking-analytics-dashboard

# Install dependencies
pip install -r requirements.txt

# Run dashboard
streamlit run presentation_dashboard.py
```

### Results Highlights
- 🥇 Random Forest Regression: 97.11% R²
- 🥈 Random Forest Classification: 81.69% accuracy
- 🥉 Neural Network Regression: 96.54% R²
- 🎯 Autoencoder Anomaly Detection: 93.92% accuracy
